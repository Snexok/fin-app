# Можно? Наушники и незваные гости

Презентация рассказывает историю покупки наушников. В ней 11 слайдов: обложка, 8 аниме-сцен, пример расчета и короткая версия трейлера. Продукт находится на стадии гипотезы, суммы приведены для иллюстрации.

Откройте готовые файлы:

- [PDF](output/trailer/mozhno-story.pdf) - версия для просмотра, слайды сохранены как изображения, без заметок.
- [PPTX](output/trailer/mozhno-story-final.pptx) - редактируемые тексты и таблица, с заметками.
- [Раскадровка](output/trailer/storyboard.png) - обзор восьми сцен.
- [Рендер слайдов](output/trailer/presentation-slides/) - PNG-превью 11 слайдов.

Проверка готовых файлов:

```sh
./scripts/story.sh check
```

Пересборка создает новые файлы в `.build/story-build-XXXXXX/export/`. Готовые экспорты в `output/trailer/` остаются без изменений:

```sh
./scripts/story.sh build
```

Сценарий, камера и звук описаны в [исходнике презентации](scripts/build-story.mjs). Подробные правила постановки находятся в [сценарии трейлера](output/trailer/entertainment-playbook.md). Исследование аналогов и прежняя презентация из 16 слайдов: [материалы исследования](research/README.md) и [PowerPoint](output/mozhno-research-playbook.pptx).

В заметках PowerPoint находятся указания для камеры, звука и переходов. Видео и звуковые дорожки пока не созданы. Для сборки нужны комплект зависимостей Codex и шрифт Arial. Подробности: [инструкция по сборке](docs/presentation-build.md).
